# 명령 단위 sudo 권한 모델 전환

## 변경 요약

저장소 전체에서 스크립트를 root로 재실행하던 방식을 제거하고, 시스템 변경이 필요한 명령에서만 `sudo` 인증 프롬프트를 사용하도록 전환했습니다.

## 주요 변경사항

- 공통 sudo 인증 함수와 명령 실행 함수를 `lib/common.sh`에 추가했습니다.
- `exec sudo ... bash` 형태의 스크립트 재실행을 제거했습니다.
- APT, systemd, 시스템 저장소, 드라이버 및 시스템 파일 변경 명령만 sudo로 실행합니다.
- 사용자 홈, resume 상태, GNOME/Xorg 사용자 세션 작업은 원래 사용자 컨텍스트를 유지합니다.
- 보안 스캔의 기본 대상은 실행 사용자의 `HOME`으로 결정합니다.

## 적용 설정

- `dev`
- `sys`
- `net`
- `ops`
- `security`
- 공통 APT 저장소 관리 계약

## 기대 효과

- sudo 재실행으로 사용자 환경과 상태 파일 소유자가 root로 바뀌는 문제를 방지합니다.
- 권한이 실제로 필요한 시점에 터미널 암호 프롬프트로 인증할 수 있습니다.
- privileged 작업 범위가 개별 시스템 명령으로 제한됩니다.

## 검증

- 전체 Bash 스크립트 `bash -n`
- ShellCheck 정적 검사
- sudo 재실행 패턴 및 이전 공통 함수 호출 부재 확인
