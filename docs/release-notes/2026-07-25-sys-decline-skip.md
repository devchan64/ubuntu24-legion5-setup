# sys 동의 거절 시 건너뛰기 처리

## 변경 요약

`scripts/install-all.sh all` 실행 중 `sys` 단계 동의 질문에 `n`을 입력하면 전체 실행이 중단되지 않고 `sys`만 건너뛰도록 변경했습니다.

## 주요 변경사항

- `sys` 단계에서 sudo 인증보다 사용자 동의 질문을 먼저 수행합니다.
- 사용자가 `sys` 단계 변경에 동의하지 않으면 오류가 아니라 정상 건너뛰기로 처리합니다.
- 공통 프롬프트 유틸에 거절 시 실패하지 않고 건너뛰기 신호를 반환하는 `confirm_or_skip`을 추가했습니다.

## 영향 범위

- `scripts/cmd/sys.sh`
- `lib/common.sh`

## 기대 효과

- `all` 실행 중 시스템 설정 변경을 원하지 않을 때 이후 `net`, `ops`, `security`, `media`, `ml` 단계로 진행할 수 있습니다.
- 동의하지 않을 단계에 대해 불필요한 sudo 인증을 요구하지 않습니다.

## 검증

- `bash -n`으로 변경된 스크립트 문법을 확인했습니다.
- `sys` 단계 동의 거절 시 종료 코드 0으로 정상 종료되는지 확인했습니다.
