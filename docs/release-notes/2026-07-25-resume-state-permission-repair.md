# resume 상태 파일 권한 복구

## 변경 요약

`~/.local/state/ubuntu24-legion5-setup` 아래 resume 상태 파일이 root 소유로 남아 있어도 실행 중 사용자 소유로 복구한 뒤 완료 상태를 기록하도록 변경했습니다.

## 주요 변경사항

- 상태 디렉터리와 기존 resume 파일의 쓰기 권한을 기록 직전에 확인합니다.
- 쓰기 불가능한 상태 경로는 명시적 sudo로 현재 사용자 소유권을 복구합니다.
- 복구 후에도 쓰기 권한이 없으면 즉시 실패합니다.

## 영향 범위

- `lib/common.sh`
- resume 완료 표시를 사용하는 모든 도메인 명령

## 기대 효과

- 과거 root 소유로 생성된 `resume.cmd:<scope>.done` 파일 때문에 단계 완료 기록이 실패하는 문제를 방지합니다.
- `sys:legion:hdmi` 같은 장시간 시스템 단계가 끝난 뒤 마지막 resume 기록에서 중단되는 상황을 줄입니다.

## 검증

- `bash -n`으로 변경된 스크립트 문법을 확인했습니다.
- 사용자 소유 임시 상태 디렉터리에서 resume 완료 기록이 정상 동작하는지 확인했습니다.
- root 소유 기존 파일 복구는 sudo 암호 입력이 필요해 실제 실행 시 복구되도록 로직만 확인했습니다.
